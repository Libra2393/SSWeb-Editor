Wii ↔ HD conversion, and cutscene marks that stick on Wii. This is the release where the editor's claims were tested against the actual games: every change below was loaded, played and re-saved in Sky Recomp or Dolphin, and the game's own save was compared with what the editor wrote.

**Use it online:** https://libra2393.github.io/SSWeb-Editor/

**Use it offline:** download `SSWeb-Editor.html` below and double-click it. It opens in your browser and works with no internet and no install.

### New
- **Import from another save…** (next to Copy to): bring a file from any other `wiiking2.sav`, Wii or HD, into the selected file, converted to the open save's format. Your save keeps its header, region and other files; on HD the file keeps its own playthrough ID. The saved-at time keeps the same clock time. A source file that is empty or has a bad checksum isn't imported, and the dialog says why. An HD file partway through the Song of the Hero quest gets a warning before it goes to Wii, where that quest has a bug.
  Tested in both games: the 83-hour Wii file and an early Wii file into Sky Recomp, and a Sky Recomp file into Dolphin. Both games loaded every file, and their re-saves changed only what any save changes: play time, saved-at and where Link stood.
- **Cutscenes tab on Wii saves** (under **Advanced**): the Wii save's cutscene block at `0xFB60` is now mapped, with its checksums, so the tab works on Wii as well as HD.
- **skip.dat on Wii:** the game reads which cutscenes you've seen from `skip.dat` beside the save, not from the save itself, and overwrites the save's copy from it. Use **⋯ → Open skip.dat…** to read the game's file in, and **Save** writes it back beside the save. Tested in Dolphin: two cutscene marks set in the editor were still there, in the save and in `skip.dat`, after the game saved.

### Fixed
- **"Skyloft — prologue done" preset** now matches a played save: it sets the Sky Keep room layout, no shield or dowsing target selected, and Skyloft as an area visited. Tested in Sky Recomp: the file loads straight into Skyloft with no opening scenes and no new-game setup.
- A new check makes sure every story preset carries what every played save has.

### Good to know
- On HD, the game's first save of a file brought over from Wii turns off one item flag (Deku Hornet, item flag 143). Every save made in HD that was checked has it off. Your hornets and their count are untouched.
- `skip.dat` and the save can disagree for files you haven't played recently. Open `skip.dat` before editing cutscenes, so the tab shows what the game uses.

### Not yet
- **HD cutscene marks:** HD's `skip.dat` has 4 more bytes per file than the save's copy, and those aren't mapped yet, so the editor doesn't write it. On HD, cutscene edits and marks brought in by an import may be undone by the game. Mapping those bytes is next.

**Keep a backup of your save before editing.**
