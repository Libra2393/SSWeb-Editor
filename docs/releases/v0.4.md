A finished-game preset, a way to empty a file, Batreaux's rewards, and a much fuller map of the save, with the research tools tucked behind an **Advanced** switch.

**Use it online:** https://libra2393.github.io/SSWeb-Editor/

**Use it offline:** download `SSWeb-Editor.html` below and double-click it. It opens in your browser and works with no internet and no install.

### New
- **Preset: 100% — at the statue before Demise.** A completed file copied from a real 100% NTSC save from GameFAQs at that exact moment: 18 hearts, every item and upgrade, maximum rupees, every bug and treasure, 80 gratitude crystals and all of Batreaux's rewards, at 83 h 01 m. Works on Wii and HD files.
- **Clear file** (HD and Sky Recomp): empties a file the way the game does, so you can start a new game in it. Checked by clearing a file and starting over in Sky Recomp.
- **Batreaux's rewards** on the Collectibles tab: all seven, from the Medium Wallet at 5 crystals to the Tycoon Wallet at 80. Untick one and he hands it over again.
- **Two more heart pieces:** Batreaux's and the Thunder Dragon's Lightning Round. 23 of 24 are now mapped.
- **Beacons tab:** the five map beacons of every area, with positions.
- **Bird statues** activated in Faron and Eldin, and the **rooms-visited** map data for every area.

### Safer saving
- **Automatic backup:** the first time you save over the opened file, the editor downloads the untouched original as `wiiking2.bak.sav` first.
- **Risky edits ask first:** 97 fields that can strand a file, such as key items, dungeon boss and key flags and "Beat dungeon" story flags, are marked ⚠ and ask before a dangerous change.
- **Presets check the target file:** applying a preset over a file that is in use or further along now says what will be lost or left mismatched.
- **Bad checksums stay visible:** a file whose checksum was already wrong when opened is no longer silently re-signed. **Recompute all checksums** still re-signs it if you confirm you want that. Clearing it, copying a good file over it, or a full-file preset still produces a valid file.

### Advanced (off by default)
Tick **Advanced** at the end of the tab bar to show the research tabs:
- **Item flags:** every item flag and counter, 193 of 267 named from the game's own item names
- **Story flag table:** all 1,190 story flags by number
- **Scene flags:** 1,313 scene flags, each described by the chest, switch, trigger or event that uses it
- **Enemies:** kills and hits taken per enemy type
- **Cutscenes** (HD): the cutscenes-seen bits stored in the save

On a real 100% save, every story, item and dungeon flag that is set now belongs to a field in the editor.

### Changed
- **Removed the "starting clothes" preset.** It was tested in Sky Recomp and Link still loaded in the knight uniform, so the flag it used doesn't control his outfit. That field is now labelled for what it does: unlocking Fi and the later Skyloft layouts.
- Every preset was re-checked on Wii and HD saves: all apply cleanly with valid checksums.

### Not mapped yet
- Beedle's heart piece and Link's outfit
- Eight chests behind bombable walls or boulders are still unverified
- Scene flags the game sets from its own code can only be found by comparing saves; the Compare tab does that
